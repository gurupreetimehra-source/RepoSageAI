
# RepoSage AI

An AI-powered assistant that helps beginners understand
and contribute to open-source GitHub issues.

## Planned Features

- Explain GitHub issues in simple language
- Identify relevant repository files
- Generate step-by-step contribution plans
- Suggest tests for proposed fixes

## Technology Stack

- Python
- Streamlit
- GitHub REST API
- Ollama
- Open-weight language model

## Status

Under development.
